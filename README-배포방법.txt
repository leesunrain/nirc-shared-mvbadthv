10K 3대 핵심훈련 계산기 v1.0.0

[구분] 신규 앱 / 기존 앱 업데이트 아님
[프로젝트] 새 Vercel 프로젝트 최초 1회 생성
[Production URL] 신규 배포 전 미정
[배포 대상] Production
[데이터] 10K 기록을 브라우저 localStorage 키 tenk-train-v1에 저장
[PWA] manifest.webmanifest, sw.js, 아이콘 포함

배포 방법
1. ZIP 압축을 풉니다.
2. Vercel에서 신규 프로젝트를 1회 생성합니다. (기존 앱 프로젝트는 선택하지 마세요.)
3. 압축을 푼 폴더 안의 index.html, manifest.webmanifest, sw.js, 아이콘 파일을 배포합니다.
4. 생성된 Production URL에서 계산 결과와 홈 화면 설치를 확인합니다.
5. 이후 업데이트는 이번에 생성한 동일 projectId와 Production URL에 배포합니다.

참고: ZIP 생성은 배포 완료를 의미하지 않습니다. 이 파일은 실제 서버에 배포되지 않았습니다.
